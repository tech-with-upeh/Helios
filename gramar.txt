HELIOS LANGUAGE SPECIFICATION
(Reverse-engineered from parser)

================================
1. OVERVIEW
================================

Helios is a UI-first hybrid language combining declarative UI with
imperative logic. It is designed for pages, views, canvas drawing,
stylesheets, and reactive state.

Core ideas:
- page() is the top-level unit
- UI elements are function-like blocks
- State is reactive and page-scoped
- Stylesheets are native language constructs
- Event handlers support inline functions

--------------------------------
2. PROGRAM STRUCTURE
--------------------------------

A Helios program is a sequence of statements:

- page declarations
- function definitions
- stylesheet declarations
- expressions
- comments

Example:

page("Home") {
    view("root") {
        text("Hello world")
    }
}

--------------------------------
3. PAGE
--------------------------------

Syntax:

page(title_or_identifier, [params...]) {
    body
}

First argument:
- string literal OR identifier

Optional parameters:
- route
- style
- cls
- id

Example:

page("Home", route="/", cls="main") {
}

Rules:
- Only one page per file (recommended)
- Page parameters are parsed specially

--------------------------------
4. UI ELEMENTS
--------------------------------

Supported UI nodes:

- view
- text
- img
- canvas

General syntax:

view(value, [params...]) {
    children
}

Rules:
- First argument is mandatory
- id parameter is NOT allowed on view

--------------------------------
5. COMMON PARAMETERS
--------------------------------

style     : dict | identifier
cls       : string | identifier
id        : string | identifier (not allowed on view)
onclick   : function
onlongpress : function

--------------------------------
6. EVENT HANDLERS
--------------------------------

Forms supported:

1) Function reference
onclick=myHandler

2) Inline def
onclick=def() {
    print("clicked")
}

3) Anonymous function
onclick=() {
    print("clicked")
}

--------------------------------
7. CANVAS
--------------------------------

Syntax:

canvas(id, width=INT|IDENT, height=INT|IDENT) {
    draw(...)
}

Rules:
- width is required
- height is required
- Missing either causes a parser error

--------------------------------
8. DRAW CONTEXT
--------------------------------

Syntax:

draw("canvasId")
draw(canvasVar)

Used only inside canvas blocks.

--------------------------------
9. STYLESHEET
--------------------------------
 
Syntax:

@stylesheet name {
    selector = {
        property: value
    }
}

To Add Style var to dom: addStyles(name)

Global stylesheet:

@stylesheet &global {
}

--------------------------------
10. MEDIA QUERIES
--------------------------------

Syntax:

media("width" > "600px") { 
    selector {
        property: value
    }
}

Media conditions use expressions, not strings.

--------------------------------
11. STATE
--------------------------------

Declare state (page-only):

@state count: 0

Update state:

@count: count + 1

Rules:
- State only allowed inside page
- State updates outside page cause an error

--------------------------------
12. LIFECYCLE HOOKS (PAGE ONLY)
--------------------------------

onmount() {
}

animatefps() {
}

listener(event) {
}

Using these outside page is invalid.

--------------------------------
13. FUNCTIONS
--------------------------------

Declaration:

def add(a, b) {
    return a + b
}

Anonymous:

() {
    print("hello")
}

--------------------------------
14. CONTROL FLOW
--------------------------------

if (condition) {
}

while (condition) {
}

for (item in collection) {
}

--------------------------------
15. EXPRESSIONS & MATH
--------------------------------

Built-in math functions:

sin(x)
cos(x)
tan(x)
sqrt(x)
pow(a, b)

--------------------------------
16. TYPE CONVERSIONS
--------------------------------

to_int(x)
to_float(x)
to_str(x)

to_str is allowed inside UI parameters.

--------------------------------
17. PLATFORM API
--------------------------------

Syntax:

Platform().method().method()

Parsed as chained platform calls.

--------------------------------
18. NAVIGATION
--------------------------------

go("route")
go(routeVar)

--------------------------------
19. COMMENTS
--------------------------------

Single-line:
# comment

Block:
 /* comment */

--------------------------------
20. ERROR RULES
--------------------------------

- Missing required arguments cause hard errors
- canvas without width/height is invalid
- id on view is forbidden
- lifecycle hooks only allowed in page
- @state only allowed in page
- Unknown keywords cause errors

--------------------------------
21. MENTAL MODEL
--------------------------------

Helios ≈ React + CSS + Canvas + scripting language

- Declarative UI
- Imperative logic
- Reactive state
- Strict parsing
- Custom runtime execution
